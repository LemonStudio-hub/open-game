# G.T.I.（全球反恐特勤组）设定集

*以下为基于官方设定框架，结合个人主张整理而成的完整组织档案。*


## 一、组织概况

**G.T.I.（Global Terrorism Intervention）** ，即**全球反恐特勤组**，是电子游戏《三角洲行动》及其衍生世界观中设立的虚构国际反恐组织。

- **组织全称**：全球反恐特勤组（Global Terrorism Intervention）
- **成立时间**：2018年
- **活跃时期**：游戏主线设定为2035年
- **组织口号**：“不让任何一个人掉队”
- **组织性质**：独立于联合国现有维和体系之外的全球性反恐机动力量
- **核心职能**：应对全球性恐怖主义威胁，维护国际和平与区域稳定


## 二、成立背景与法理依据

### 2.1 历史原点：摩加迪沙之殇

1993年，美军三角洲特种部队与游骑兵在索马里首都摩加迪沙执行“哥特蛇”行动，旨在抓捕当地军阀艾迪德。行动因情报失误、指挥链混乱及国际协调缺位而失败，造成美军重大伤亡，即“黑鹰坠落”事件。

这一事件暴露了国际社会在应对地区危机时的制度性缺陷——**联合国维和机制反应迟缓、多国部队指挥权割裂、精锐特种力量缺乏合法且高效的全球部署通道**。该事件成为G.T.I.创立的“精神原点”。

### 2.2 筹备与成立

经历1993年索马里危机后，国际社会对建立一支**可快速部署、拥有合法授权、具备顶尖作战能力**的全球反恐力量进行了长期讨论。经过各大国多年磋商与制度设计：

**2018年**，经联合国安理会决议，**G.T.I.（全球反恐特勤组）** 正式成立。

该组织**独立于联合国现有维和体系之外**，在人事、预算与行动指挥上保有高度自主权，但名义上隶属于联合国维和预算框架，其法律地位由安理会决议予以确认。

### 2.3 初期武装力量构成

组织成立初期，其精锐武装核心主要抽调自**美军三角洲特种部队**，以继承其在特种作战领域的经验与传统。随后数年间，通过各成员国派遣制度，逐步吸纳来自全球的特战精英，最终演化为一支由世界顶尖特战人员组成的、可全球部署的反恐机动力量。

### 2.4 阿萨拉部署授权

鉴于阿萨拉地区局势持续恶化，哈夫克集团的活动对区域乃至全球安全构成重大威胁，联合国安理会通过后续决议，**授权G.T.I.进驻阿萨拉地区，并授权其采取一切必要手段维护地区稳定**。

该授权构成G.T.I.在阿萨拉一切行动的最高法理依据。


## 三、组织架构

### 3.1 顶层治理结构

G.T.I.实行常务委员会集体领导制。

**常务委员会**：由联合国安理会指派委员组成，全权负责组织所有重大决策。委员在法理上向安理会负责，但在实际操作中拥有高度独立的决策权限。

> **制度张力**：委员会名义上由安理会指派，但一旦任命后“全权负责”，实质上切断了安理会对具体行动的实时干预通道。这一“委托-代理”困境构成G.T.I.一切内部政治冲突的制度根源。

### 3.2 预算与财政制度

G.T.I.的运营预算由**所有成员国按比例平摊**，名义上列入联合国维和预算科目，接受联合国名义上的预算框架管理。

### 3.3 附属机构设置

| 机构名称 | 职能描述 |
|---------|---------|
| **常务委员会** | 由安理会指派委员组成，全权负责组织决策 |
| **军事参谋团** | 由各成员国派遣高级军官组成，负责作战计划制定与战术协调 |
| **独立监察办公室** | 名义上负责内部审计与合规监督，受常务委员会节制 |
| **特勤处** | 一线作战力量，由各兵种干员组成，即玩家所在作战单元 |

### 3.4 全球分布与部门设置

G.T.I.在全球设有多处分部，干员来自各成员国。

- **已知分部**：北美分部、亚洲分部、大洋洲分部、非洲分部等
- **核心部门**：特勤处下辖战斗、医疗、战术、研发等核心部门
- **现任总指挥**：多米尼克·圣地亚哥 中将

### 3.5 兵种与干员体系

## 四、核心目标与主要行动

### 4.1 核心任务

1. 遏制**哈夫克集团**对全球安全的威胁
2. 争夺并控制**曼德尔砖**——哈夫克研发的高价值军事计算模块，内含武器技术或战略情报
3. 阻止哈夫克秘密实验
4. 破坏 **“巴别塔计划”**
5. 瓦解哈夫克太空军事布局

### 4.2 重要时间节点

- **2032年**：G.T.I.以安理会反恐授权名义介入阿萨拉地区
- **2035年**：派遣精英干员深入阿萨拉，全面调查哈夫克集团非法活动

### 4.3 主要行动记录

- **“钻石酒店”行动**：争夺曼德尔砖，最终失利
- **飞升者行动**：阻止哈夫克火箭发射计划，植入G.T.I.自主开发的 **“密涅瓦”（Minerva）程序**
- **“回响”行动** ：围绕G.T.I.高层内鬼的复杂谍战博弈
- **“衔尾蛇”行动**：为追回曼德尔砖发起的肃清行动
